# Playground

Draws Mermaid, PlantUML, or Graphviz DOT source in the browser as you type, with `sirene-core`
built for WebAssembly. The page's address keeps the source, so a link to it opens the same
diagram. The `edit` button on any diagram in these docs does the same for that diagram.
