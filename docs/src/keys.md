# Keys

Secondary is Cmd on macOS and Ctrl elsewhere. Keys marked "drawing" act only while the drawing
has the keyboard (click it first); while the source pane or a label field has it, Undo, Redo, and
Select All act on that text instead.

## Files and windows

| Keys | Action |
|---|---|
| secondary-n | New document |
| secondary-o | Open |
| secondary-s | Save |
| secondary-shift-s | Save As |
| secondary-r | Reload from disk |
| secondary-shift-e | Export as PNG |
| secondary-shift-c | Copy the drawing as an image |
| secondary-w | Close the window |
| secondary-q | Quit |
| secondary-e | Show or hide the source pane |

## Editing

| Keys | Action |
|---|---|
| secondary-shift-n | Add a node, linked from the selected node |
| enter (drawing) | Edit the selected item's label |
| backspace, delete (drawing) | Delete the selection |
| escape (drawing) | Clear the selection |
| secondary-z | Undo |
| secondary-shift-z | Redo |
| secondary-a | Select every node and edge (drawing), or all text |
| tab, shift-tab (drawing) | Select the next or previous node |

## View

| Keys | Action |
|---|---|
| secondary-= or secondary-+ | Zoom in |
| secondary-- | Zoom out |
| secondary-0 | Actual size |
| secondary-9 | Fit the window |
| secondary-8 | Fit the selection |
| arrows (drawing) | Pan; shift for further |
| secondary-scroll | Zoom |

## Mouse

| Gesture | Action |
|---|---|
| click | Select a node or edge, or clear the selection on empty space |
| shift-click | Add to or remove from the selection |
| double-click | Edit a label |
| drag from a node to a node | Connect them |
| drag empty space, or scroll | Pan |
