sirene

A local editor and viewer for Mermaid, PlantUML, and Graphviz DOT diagrams. Edit the source or the drawing, and render SVG, PNG, or text from the command line. One binary, no browser.

Install

      

        
        
        
        
      


      

        

          $ curl --proto '=https' --tlsv1.2 -fsSL https://raw.githubusercontent.com/jaemk/sirene/main/bin/install.sh | sh
          
        

        
Linux gets the static command-line build; see Install for the editor build.

      


      

        

          $ brew tap jaemk/sirene https://github.com/jaemk/sirene
$ brew trust jaemk/sirene
$ brew install sirene
          
        

        
On macOS, brew install --cask sirene installs Sirene.app instead.

      


      

        

          $ cargo install sirene
          
        

        
Add --no-default-features for the command line only.

Edit either side

        
Type in the source and the drawing follows. Rename, add, connect, and delete on the
           drawing, and each change lands in the source as an ordinary text edit, with comments
           and formatting kept.

        The editor
      

      

        
Render anywhere

        
sirene svg, png, and ascii render a file,
           stdin, or a whole directory, and --watch keeps the images current. PNGs
           use embedded fonts, so they are the same on every machine.

        Command line
      

      

        
Errors that point

        
Diagnostics name the line and column, and a diagram with a mistake is still drawn.
           Over 30 Mermaid diagram kinds, 20 PlantUML kinds, and Graphviz DOT are drawn.
