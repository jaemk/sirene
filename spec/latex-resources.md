# LaTeX Resources

What the typesetter of `latex-math.md` embeds or generates: the math font, the symbol and
command tables, and their licenses and size cost. Status: research; the open items are in
LRES-T.

## LRES-1 Math font

One OpenType font with a MATH table, embedded with its license beside the bundled Noto Sans
files and a THIRD-PARTY-NOTICES entry (the attribution rule). Candidates to measure (LRES-T1):
STIX Two Math, Latin Modern Math, Noto Sans Math, Fira Math, Libertinus Math, and TeX Gyre
math fonts. For each: license and whether it allows embedding and subsetting, file size before
and after subsetting to the command table's glyphs, glyph coverage (Greek, Fraktur, blackboard
bold, script, arrows, relations, big operators and their size variants), and MATH table
completeness (variants and assemblies for delimiters, radicals, and braces).

Findings so far (2026-11-22):

| Font | License | Size | Notes |
|---|---|---|---|
| Latin Modern Math | GUST Font License (legally the LPPL 1.3c or later) | 733,736 bytes (`latinmodern-math.otf`, CTAN `fonts/lm-math/opentype`) | Computer Modern look, closest to LaTeX output; the license's rules for modified (subset) versions are to read (LRES-T4). |
| STIX Two Math | SIL OFL 1.1 (STIX Fonts Project Authors, 2001-2021) | not measured; the CTAN path tried was wrong | Has a MATH table; formulary vendors it as a test font. The OFL has a reserved font name, so a subset needs a new name. |
| KaTeX fonts (20 faces: AMS, Caligraphic x2, Fraktur x2, Main x4, Math x2, SansSerif x3, Script, Size1 to Size4, Typewriter) | SIL OFL 1.1, from the font's name table: Copyright 2009-2010 Design Science, Inc. (MathJax) and 2014-2018 Khan Academy; the KaTeX repo carries no separate font license file | 513,664 bytes as TTF in total (Main-Regular 53,580; AMS-Regular 63,632), 259,792 bytes as WOFF2; 3 formats per face upstream | No MATH table (checked on `KaTeX_Main-Regular.ttf`). Layout uses KaTeX's own metrics file, `src/fontMetricsData.js` (2,077 lines, 93.6 KB, generated by `buildMetrics.sh`, five numbers per glyph: depth, height, italic, skew, width). Matches what Mermaid users see. |
| Noto Sans Math, Fira Math, Libertinus Math, TeX Gyre | not read | not measured | Candidates to check. |

The choice is between a MATH-table font (layout from the font, LRES-T1) and the KaTeX font set
with its metric tables. The first follows MathML Core (LPA-4) and is one 734 KB file; the
second matches what Mermaid users see, is smaller (514 KB as TTF, and the 20 faces can be
subset), and needs the metrics table and KaTeX's delimiter and stretchy-shape rules, which
it draws as stacked glyphs from Size1 to Size4 and as SVG paths rather than from MATH
assemblies. Either way the font ships in the binary and the wasm package. The decision is
LMATH-11.

## LRES-2 Text font in formulas

`\text`, `\mathrm`, and `\mathbf` take their glyphs from the math font's upright and bold
styles, or from the bundled Noto Sans (DISPLA-4) so formula text matches the diagram's own. To
decide (LRES-T2): whether the math font's Latin letters, which are designed with its math
italic, are enough, or a second font is embedded.

## LRES-3 Symbol and command table

About 1,000 commands map to a Unicode scalar and a TeX atom class (ordinary, operator, binary,
relation, opening, closing, punctuation). Sources to compare (LRES-T3): the Unicode math class
data (`MathClass.txt`), `unicode-math`'s symbol table, KaTeX's `symbols.js` and function
definitions, and MathJax's TeX input maps. The table is data, generated by a script kept in the
repo, checked in, and tested against the font's coverage so no command names a glyph the
subset lacks. Each source's license decides whether the table may be derived from it
(LRES-T4); the attribution rule applies to any derived data.

## LRES-4 Size budget

The docs site loads `sirene-wasm`, and the CLI ships as one binary. Budget to set (LRES-T5):
the font subset in KiB, the table in KiB, and the effect on the wasm download and the binary.
A feature flag (`math`, as `png` is today) could keep the font out of a build that does not
draw formulas; to decide.

## LRES-5 Build and generation

Generated files carry a header saying how to regenerate them, and a test fails when they are
stale. No network access at build time (the workspace builds offline); the font and the source
data are checked in.
